# SG4 - Understanding Classes and Objects
## Class Name
Instruments
## Class Description

## Properties
| Property | Data Type | Description |
|---|---|---|
|Material |String |What the instrument is made out of. |
|Type |String |Which categorie or family it belongs to.(String, Woodwind, Brass, Percussion, Keyboard) |
|Weight |Float |How heavy or light it is. |
|Name |String |It is the name of the iinstrument. |
## Methods
| Method | Description |
|---|---|
|Play |It is the action that makes the instrument produce sound/music |
|Tune |It changes the pitch and creates harmony |
|Repair |Fixes the instrument from damage so that it can still be used. |
